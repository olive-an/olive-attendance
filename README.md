# olive-attendance
おりーぶ庵 打刻管理システム Ver.2

PCとスマホの打刻をGoogleスプレッドシートに保存し、同期する勤怠打刻アプリ(PWA)。

## 構成
| ファイル | 役割 |
|---|---|
| index.html / style.css / app.js | 画面(GitHub Pagesで公開) |
| config.js | Apps Script WebアプリのURLを設定する |
| sw.js / manifest.webmanifest | PWA(ホーム画面追加) |
| gas/Code.gs | サーバー側(Google Apps Script)。シートの読み書き・認証・承認 |

## 仕様
- 認証: 従業員番号 + 数字6桁PIN。PINはハッシュ化して保存。5回間違えると15分ロック。初回ログイン時にPIN変更を必須とする
- 管理者: Script Properties の `ADMIN_ID`(初期値 11 = 岩久保)の1名のみ。判定はサーバー側
- 勤務区分: 日勤 / 夜勤 / 直行直帰。夜勤は日付をまたいで1件の勤務として記録(勤務日は出勤日)
- 打刻時刻は必ずサーバー時刻(端末の時計は使わない)
- 打刻修正: 従業員が申請 → 管理者が承認/却下。申請・修正前後の値・承認者・承認日時・コメントを「修正申請」シートに残す。元の打刻は承認時に更新される(修正前の値は申請行に残る)
- 休憩控除・勤務先は「設定」シートで変更できる

## シート(スプレッドシート おりーぶ庵_打刻管理_Ver1)
従業員 / 打刻 / 修正申請 / 設定 / 初期PIN配布(配布後に削除)

## 導入手順
1. スプレッドシートの「拡張機能 → Apps Script」を開き、`gas/Code.gs` の内容を貼り付けて保存
2. 関数 `setup` を実行(権限を承認)。続けて `issueInitialPins` を実行
3. 「初期PIN配布」シートの番号とPINを本人に直接伝え、配布後にシートを削除
4. 「デプロイ → 新しいデプロイ → ウェブアプリ」: 実行ユーザー=自分、アクセスできるユーザー=全員。発行された `…/exec` のURLを `config.js` に設定して push
5. 公開画面 https://olive-an.github.io/olive-attendance/ で動作確認

## 注意
- 個人情報(従業員名簿など)をこのリポジトリに置かないこと(公開リポジトリ)
- コードを変更したら Apps Script で「デプロイを管理 → 新バージョン」を行う
- 打刻シートは年1回程度、別ファイルへ退避する(読み込み速度のため)
